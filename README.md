# -v2rayN-Yandex-Music-Yandex-Disk-Bitrix24-Microsoft-login-Power-BI-
Конфиг для v2rayN с раздельной маршрутизацией: Yandex Music, Yandex Disk, Bitrix24, Microsoft login и Power BI выводятся напрямую, остальной трафик идет через proxy. Решение снижает нагрузку на сервер и улучшает стабильность работы приложений, которым нежелателен проход через VPN.
